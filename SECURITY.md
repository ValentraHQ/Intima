# Security Policy

> **INTIMA** · PRODUCT OWNER & ENGINEER: Surely Win Dilag
> Prepared by: Surely Win Dilag · Designation: Product Owner & Engineer · Project: INTIMA · Document Status: Draft

INTIMA is pre-release and not deployed anywhere.

- Report suspected vulnerabilities privately through GitHub Security Advisories on this repository ("Report a vulnerability"). Do not open public issues.
- Never include real personal data, credentials or adult media in reports.
- Suspected illegal content (including CSAM) must never be uploaded, attached or reproduced anywhere in this repository or its issues.
