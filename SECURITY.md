# Security Policy

> **INTIMA** · PRODUCT OWNER & ENGINEER: Surely Win Dilag
> Prepared by: Surely Win Dilag · Designation: Product Owner & Engineer · Project: INTIMA · Document Status: Draft

INTIMA is pre-release and not deployed anywhere.

- Report suspected vulnerabilities privately through GitHub private vulnerability reporting, which is enabled on this repository: go to the **Security** tab and choose **Report a vulnerability**, or open <https://github.com/ValentraHQ/Intima/security/advisories/new>. Only the reporter and the repository maintainers can see the report. Do not open public issues, discussions or pull requests about a suspected vulnerability.
- Never include real personal data, credentials or adult media in reports.
- Suspected illegal content (including CSAM) must never be uploaded, attached or reproduced anywhere in this repository or its issues.
